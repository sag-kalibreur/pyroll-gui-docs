Working Diameter – Flat Rolling Correction

PyRoll GUI  |  Date: September 2026

1. Introduction

For a flat pass (FlatGroove, i.e. a pass without any lateral groove shape), PyRolL Core's standard formula for the working radius is:

\[ r_{\text{work}} = r_{\text{nominal}} - \text{groove\_factor} \]

For a FlatGroove, groove_factor is always \(0\) (the groove contour is a flat line at \(y = 0\)), so this reduces to \(r_{\text{work}} = r_{\text{nominal}}\) — the working radius equals the nominal roll radius, unmodified.

This overestimates the effective rolling radius: the actual contact between roll and workpiece happens below the nominal roll surface, at roughly half the height reduction. Left uncorrected, this error propagates into the contact length, elongation, roll force and roll torque (typically 2–5 % for reductions above 10 mm). PyRoll WebGUI therefore applies a dedicated correction for flat passes.

2. Corrected Working Radius

The correction subtracts half of the total height reduction \(\Delta h\) from the nominal radius:

\[ r_{\text{work}} = r_{\text{nominal}} - \frac{\Delta h}{2} \qquad \text{where} \qquad \Delta h = h_{\text{in}} - g \]

where \(g\) is the roll gap and \(h_{\text{in}}\) is the equivalent incoming bar height of the in-profile (see Section 3). If \(\Delta h \le 0\) (gap at or above the incoming height, i.e. no reduction), no correction is applied and PyRolL's default formula is used instead.

The working diameter shown in the Results table is simply \(D_{\text{work}} = 2 \, r_{\text{work}}\).

3. Equivalent Height — Which Formula Applies?

PyRolL Core defines a generic equivalent_height for any profile as:

\[ h_{\text{in}} = \sqrt{ A \cdot \frac{h}{w} } \]

where \(A\) is the cross-section area and \(h\), \(w\) are the profile's bounding height and width. For a round profile (\(h = w = D\)), this reduces to \(h_{\text{in}} = \sqrt{A}\).

ℹ Important: this generic formula is not what applies once a profile is the in-profile or out-profile of an actual roll pass. In that context, the pyroll-lendl-equivalent-method plugin overrides equivalent_height with the Lendl equivalent-height method, which derives it from the actual filled (pillar-model) cross-section area instead of the simple \(\sqrt{A \cdot h/w}\) approximation: \[ h_{\text{in}} = \frac{A_{\text{Lendl}}}{w_{\text{Lendl}}} \] Since every in-profile/out-profile inside a simulated pass is a roll-pass profile, this Lendl-based value is what the flat-pass working-diameter correction above actually uses — not the generic formula. The two values are usually close but not identical; see the worked example below.

4. Worked Example

A round bar of 50 mm diameter enters a flat pass with a roll gap of 35 mm and a nominal roll diameter of 450 mm (nominal radius 225 mm):

QuantityValue
Nominal radius \(r_{\text{nominal}}\)225.00 mm
Roll gap \(g\)35.00 mm
Equivalent incoming height \(h_{\text{in}}\) (Lendl method)45.31 mm
Height reduction \(\Delta h = h_{\text{in}} - g\)10.31 mm
Working radius \(r_{\text{work}} = r_{\text{nominal}} - \Delta h / 2\)219.85 mm
Working diameter \(D_{\text{work}}\)439.69 mm

For reference, the generic \(\sqrt{A}\) formula (not the one actually applied) would give \(h_{\text{in}} \approx 44.28\) mm and a working diameter of \(\approx 440.72\) mm — about 1 mm higher. This small difference is expected and explained entirely by Section 3, not by any inaccuracy in the correction itself.

5. Applicability

⚠ FlatGroove only: this correction applies exclusively to passes using a FlatGroove. For all other groove types (round, oval, square, diamond, box, spline, …) PyRolL Core's standard \(r_{\text{work}} = r_{\text{nominal}} - \text{groove\_factor}\) formula is used unmodified, since those groove shapes already yield a meaningful, non-zero groove_factor.
