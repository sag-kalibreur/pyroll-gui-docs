1. Overview

The Groove Calculator tab computes a complete, pass-by-pass elongation distribution for a groove series, given only the initial and final cross-section area, a distribution factor \(Z\), and the number of passes \(n\). It replaces manual, iterative groove-by-groove calculations with a single calculation covering the whole series at once.

Three series types are supported:

  • Round ↔ Oval series: main passes use round grooves, intermediate passes use oval grooves.
  • Square ↔ Diamond series: main passes use square grooves, intermediate passes use diamond grooves.
  • Box series: all passes use box grooves with alternating H/V orientation (see section 12).

For each mode, the tab shows a result table and groove preview plots for both the main passes and the intermediate passes, and can transfer the calculated series directly into Pass Design or save individual grooves into the Groove Library.

2. Round ↔ Oval vs. Square ↔ Diamond

The mode switch at the top of the tab selects which groove series is calculated. Switching modes only changes which parameter panels, result tables and plots are shown — the Main Parameters (\(A_0\), \(A_E\), \(Z\), \(n\)) and the Start Roll Ø are remembered separately for each mode, so switching back and forth does not lose previously entered values. The default roll diameter is 400 mm for the Round and Square series (typical for intermediate mills) and 700 mm for the Box series. The third button, 📦 Box series, selects the roughing-mill box sequence described in section 12.

3. Main Parameters

The Main Parameters panel defines the overall elongation task (the Box series has additional fields, see section 12):

FieldMeaning
\(A_0\) [mm²]Initial cross-section area (input stock)
\(l_0\) Ø / □ [mm]Equivalent initial diameter (Round mode) or side length (Square mode) — bidirectionally linked to \(A_0\)
\(A_E\) [mm²]Final (target) cross-section area
\(l_1\) Ø / □ [mm]Equivalent final diameter / side length — bidirectionally linked to \(A_E\)
\(Z\)Distribution / degression factor (\(Z = 1\) gives a uniform elongation distribution across all passes)
\(n\) (passes)Number of main passes in the series

Editing \(A_0\)/\(A_E\) automatically updates the equivalent diameter/side length fields and vice versa. Below the inputs, a live preview shows \(\lambda_{\text{total}}\), \(\lambda_m\) (mean elongation per pass) and \(\varepsilon_{Am}\) (mean logarithmic strain per pass) — updated as you type, even before pressing Calculate ▶.

Round ↔ Oval mode: Main Parameters, Round Groove Factors, and Oval Groove Factors (intermediate).

Square ↔ Diamond mode: Main Parameters, Square Groove Factors, and Diamond Groove Factors (intermediate).

5. Oval / Diamond Groove Factors (Intermediate)

Intermediate passes (Oval between round passes, Diamond between square passes) are estimated from the geometric mean of the two adjacent main-pass areas, combined with a Wusatowski area form factor. Their geometry is controlled by:

Oval (Round mode)

FactorMeaning
\(b/h\)Width-to-height aspect ratio of the oval
\(r_2/h\)Main contour radius \(r_2\) relative to the oval height
\(r_1/s\)Edge radius \(r_1\) relative to the groove gap \(s\)
\(s/h\)Groove gap \(s\) relative to the oval height

Diamond (Square mode)

FactorMeaning
\(w/h\)Diagonal aspect ratio of the idealised diamond (rhombus) cross-section
\(R_{\text{start}}\), \(R_{\text{end}}\) [mm]Main corner radius \(r_2\) of the first and last intermediate pass; interpolated linearly in between
\(r_1/s\)Edge radius \(r_1\) relative to the groove gap \(s\)
\(s/h\)Groove gap \(s\) relative to the diamond diagonal \(h\)
ℹ The diamond tip angle is not a free input — it is computed directly from the \(w/h\) diagonal ratio (\(\alpha = 2 \cdot \arctan(w/h)\)), since for an idealised rhombus cross-section the two are geometrically coupled.

6. Calculate

Press Calculate ▶ to compute the full pass-by-pass elongation distribution using the current parameters. Both result tables and both plot galleries (main and intermediate passes) are populated at once.

7. Result Tables

The main passes table lists, for each pass: the distribution exponent \(Z^y\), elongation \(\lambda_i\), cross-section area \(A_s\), equivalent diameter/side length, groove edge/main radii \(r_1\)/\(r_2\), groove gap \(s\), and flank angle \(\alpha\).

The intermediate passes table lists the same geometry columns for the Oval/Diamond grooves between each pair of main passes (including the initial "0 → 1" step from the input stock to the first main pass), using \(w\)/\(h\) instead of the equivalent diameter/side length.

8. Groove Preview Plots

Below each result table, a gallery of groove preview plots is shown — one per pass. Click any thumbnail to open it enlarged in a full-screen gallery view, with ‹/› arrow buttons (or the arrow keys / Esc) to navigate between grooves without closing the gallery.

9. Save to Groove Library

💾 Save to Groove Library opens a modal listing every calculated groove (main and intermediate passes) as a selectable row, with an editable name, its type, gap, and a live preview plot. Select any subset, choose a target library (or create a new one on the fly with + New Library), and save — existing names are flagged with a confirmation prompt before being overwritten.

10. Use in Pass Design

▶ Use in Pass Design builds a complete Pass Design sequence from the calculated series, alternating intermediate and main passes in the correct order (e.g. Oval → Round → Oval → Round…), using the Start Roll Ø field as the nominal roll diameter for every pass (a Box series uses one groove type with alternating H/V orientation). The app then switches to the Pass Design tab so roll diameter and friction can be fine-tuned per pass before simulating.

  • If Sequence 1 is still untouched (the default, empty first row), it is silently replaced with the new sequence.
  • Otherwise you are asked to confirm — overwrite Sequence 1, or add the new passes as an additional sequence instead.
  • The calculated starting size (\(l_0\)) can also be transferred to the In Profile tab: if its shape already matches the calculated series it is updated silently, otherwise you are asked to confirm before the shape/value is overwritten.

11. Reset

↻ Reset restores every field in the Groove Calculator tab to its default values and clears the result tables and plots. All fields are also automatically reset whenever a new project is started (File → New).

12. Box series (Kastenkaliber)

The third mode, 📦 Box series, calculates a roughing-mill sequence in which all passes use the same groove type (BoxGroove) and only the orientation alternates between horizontal (H) and vertical (V). After every pass the bar is turned by 90°, so the next pass reduces the width of the previous one. There are no intermediate grooves — one parameter set, one result table and one plot gallery.

Unlike round or square bars, a box bar has an independent width and height. The area chain \(A_0 \rightarrow A_E\) is therefore only the first step; each pass additionally has to be split into a height \(h_1\) (the reduced dimension) and a width \(b_1\) (the spread).

12.1 Calculation

  1. The target area of every pass follows from \(A_0\), \(A_E\), \(Z\) and \(n\) exactly as in the other modes.
  2. The logarithmic area reduction is re-weighted with \(k_V\) (see 12.3); the total \(A_0 \rightarrow A_E\) is unchanged.
  3. For each pass, \(h_1\) is found by bisection so that the resulting bar area equals the target area, with the width given by Wusatowski's spread law — offline and instant, no backend call.
\(b_1 = b_0 \cdot (h_1/h_0)^{-w}\)
\(w = 10^{-1.269\,(h_0/2R)^{0.556}\,b_0/h_0}\)   for \(h_1/h_0 \ge 0.5\)
\(w = 10^{-3.457\,(h_0/2R)^{0.968}\,b_0/h_0}\)   for \(h_1/h_0 < 0.5\)
\(A = b_1 h_1 - (4-\pi)\,r_2^2\),   \(R = D/2 - 0.46 \cdot \text{depth}\)

This is the same closed formula the Pass Design simulation uses for box passes when the Wusatowski spreading equation is selected. The calculator sets the velocity coefficient to \(c = 1\); PyRolL's own value is about 0.99, so a following simulation typically gives a width about 1–2 % smaller and an area up to about 1.6 % smaller than the calculated one. The pass heights agree to better than 0.1 %.

12.2 Parameters

FieldMeaning
\(A_0\), \(b_0\), \(h_0\), \(r_0\) [mm]Start bar: width, height and corner radius. \(h_0\) is the dimension reduced in the first pass. The fields are linked: changing \(A_0\) rescales \(b_0\) and \(h_0\) at the current ratio, changing \(b_0\)/\(h_0\)/\(r_0\) recalculates \(A_0 = b_0 h_0 - (4-\pi) r_0^2\).
\(A_E\) [mm²]Target end area. The final \(b \times h\) is a result, not an input.
\(Z\), \(n\)As in the other modes (\(n \ge 2\)).
\(k_V\) (V/H)Share of a V pass in the logarithmic area reduction relative to an H pass (default 0.8).
Start Roll Ø [mm]Nominal roll diameter for all passes, needed for the spread (default 700 mm; 400 mm in the Round and Square modes).
First passOrientation of pass 1 (H or V); the following passes alternate.

The Box Groove Factors panel derives the groove of each pass from \(h_1\) and \(b_1\):

FactorMeaning
\(s/h\)Roll gap \(s\) relative to the pass height \(h_1\); the depth is \((h_1 - s)/2\) (default 0.38)
\(r_2/h\)Corner radius \(r_2\) (flank/ground) relative to \(h_1\) (default 0.13)
\(r_1/s\)Edge radius \(r_1\) relative to the gap \(s\) (default 0.2)
\(\alpha\) [°]Flank angle against the horizontal — a steep flank is a large angle (default 77°)
\(w_u/b\)Usable groove width relative to the expected bar width \(b_1\), ≥ 1 (default 1.1)

The ground width follows as \(w_{\text{ground}} = w_u - 2 \cdot \text{depth}/\tan\alpha\). The defaults are taken from real roughing-mill box grooves (\(\alpha \approx 70\)–76°, \(s/h \approx 0.37\)–0.38).

Box series: Main Parameters (with \(k_V\), Start Roll Ø and First pass) and Box Groove Factors.

12.3 Steering the end shape with \(k_V\)

In practice an H pass mainly flattens the bar and widens it, while a V pass pushes it back towards a square. With equal reductions in every pass (\(k_V = 1\)) a sequence that ends with a V pass therefore still ends too wide. \(k_V < 1\) makes the V passes lighter and the H passes heavier, which moves the end profile towards a square; \(k_V > 1\) does the opposite. The weights apply to the pass orientation, not to the pass number, so the effect is the same for an H start or a V start.

Example with the defaults (180 × 180, \(A_E = 14000\) mm², \(n = 4\), H first, \(D = 700\) mm):

\(k_V\)Reduction per pass (H / V / H / V)Final bar\(b/h\)
1.018.9 / 18.9 / 18.9 / 18.9 %109.6 × 129.41.18
0.919.8 / 18.0 / 19.8 / 18.0 %113.2 × 125.31.11
0.820.8 / 17.0 / 20.8 / 17.0 %117.4 × 120.91.03
0.721.9 / 15.9 / 21.9 / 15.9 %122.5 × 116.10.95
ℹ Small differences in the reductions are enough to change the end shape clearly. A sequence that ends with an H pass (e.g. \(n = 3\), H first) ends wider than high even at \(k_V = 0.8\) (about 91.7 × 154.0, \(b/h \approx 1.68\)) — that is typical for such a sequence. A V-first sequence works the same way; an odd pass count such as 7 passes ends with a V pass again.

12.4 Result table, warnings and plots

The result table contains, per pass: orientation (H/V), \(Z^y\), \(\lambda_i\) (including the \(k_V\) weighting), \(A_s\), \(h_1\), \(b_1\), \(b_1/h_1\), draught \(h_1/h_0\), spread \(b_1/b_0\) and the groove data \(r_1\), \(r_2\), gap \(s\), depth, usable and ground width and \(\alpha\). Warnings are shown below the table:

  • Target area not smaller than the incoming bar — no reduction possible; check \(A_E\), \(Z\) and the start size.
  • Ground width not positive — increase \(w_u/b\) or \(\alpha\), or lower the depth (error).
  • Ground width smaller than the incoming width — the bar enters touching the flanks.
  • Step of the spread law at \(h_1/h_0 = 0.5\) — the target area lies in the jump of the formula; the closest solution is used.

The groove preview plots work as in the other modes (click for the enlarged gallery view).

12.5 Save to Groove Library and Use in Pass Design

  • Save to Groove Library stores the selected passes as BoxGroove entries.
  • Use in Pass Design builds the sequence with alternating orientation, starting with the chosen first pass, using the Start Roll Ø for every pass. The In Profile is set to the box shape (width, height, corner radius); for a V-first sequence width and height are swapped accordingly, so that \(h_0\) is the dimension reduced in the first pass.
  • Reset restores all box fields, including \(k_V\) and the roll diameter.
💡 The calculation is a design estimate. For the final tuning run the simulation in Pass Design and, if needed, use its spread correction.
